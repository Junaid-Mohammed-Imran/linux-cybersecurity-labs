## Practical Security Exercise

### Scenario

A college website has the following security situation:

- Students log in using a username and password.
- Students can view their marks but cannot edit them.
- The website uses HTTPS.
- A firewall controls incoming network traffic.
- The server software is outdated and has a known vulnerability.
- An attacker sends students fake messages asking them to enter their passwords on a fake website.

### Security Analysis

**1. Authentication:**  
Username and password are used to verify the student's identity.

**2. Authorization:**  
Students can view their marks but are not authorized to modify them.

**3. Confidentiality:**  
HTTPS helps protect information while it is transmitted.

**4. Integrity:**  
Students cannot directly modify their marks.

**5. Vulnerability:**  
The outdated server software contains a known security weakness.

**6. Threat:**  
The attacker attempting to steal student credentials is a threat.

**7. Phishing:**  
The fake messages and website are used to trick students into revealing passwords.

**8. Defense in Depth:**  
Using multiple security controls, such as authentication, HTTPS, firewall rules and secure software updates, provides multiple layers of protection.
